# Day 10:

Learning Today: Today I have learned about Three.js Camera Control and Animation in which I have covered the following topics:-

1. OrbitControls for interactive camera movement and orbiting around 3D objects.
2. Enabling damping to create smooth and natural camera controls.
3. Setting camera zoom limits using minDistance and maxDistance.
4. Animating 3D objects inside the Three.js render loop.
5. Using THREE.Clock to track animation time.
6. Understanding delta time and using it for frame-rate independent animations.
7. Creating smooth idle rotation animations for 3D objects.
8. Animating camera positions using lerp (Linear Interpolation).
9. Creating smooth camera transitions between different positions.
10. Implementing clickable camera focus points for different product views.
11. Combining OrbitControls with custom camera animations.
12. Creating a responsive Three.js product showcase scene.

In this project I have created a small "Product Showcase" scene featuring a custom 3D laptop model built using Three.js geometries. I have implemented OrbitControls with damping and camera distance limits for interactive navigation. I have also added an idle rotation animation using Clock and delta time, along with smooth camera movement using lerp. Moreover, I have created clickable Front, Top, and Side camera focus buttons that smoothly move the camera to different viewing positions. The project also includes responsive resizing and proper cleanup of Three.js resources.

Technologies Used:

1. Next.js
2. React
3. Three.js
4. JavaScript
5. OrbitControls
