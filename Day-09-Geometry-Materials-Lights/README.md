Day 9:

Learning Today: Today I have learned about Three.js Geometry, Materials, Lights, and Shadows in which I have covered the following topics:-

1. Geometry basics including BoxGeometry, SphereGeometry, TorusGeometry, and PlaneGeometry.
2. Materials including MeshBasicMaterial, MeshStandardMaterial, and MeshPhysicalMaterial.
3. Understanding the difference between materials that react to lights and materials that do not.
4. Lighting basics including AmbientLight, DirectionalLight, PointLight, and SpotLight.
5. Shadow basics including castShadow, receiveShadow, and enabling the renderer's shadow map.
6. Light intensity, position, and different lighting setups.
7. Material properties including roughness, metalness, clearcoat, and clearcoatRoughness.
8. Using lil-gui to control lights and material properties in real time.

In this project I have made a small "Material Museum" scene containing 6 different 3D objects using Box, Sphere, and Torus geometries with different materials. I have also added a Plane as a floor, implemented 4 different types of lights, enabled shadows, and created a Light Setup Experiment to switch between Ambient, Directional, Point, Spot, and All Lights. Moreover, I have added a lil-gui panel to tweak light intensity, light positions, and material properties live without restarting the application. I have also added object animations, responsive resizing, and proper cleanup for Three.js resources.

Technologies Used:

1. Next.js
2. React
3. Three.js
4. JavaScript
5. lil-gui
