# Iventions – International Event Agency

A creative frontend website inspired by Iventions, an international event agency focused on creating impactful experiences across events, exhibits, and sports.

##  About the Project

This project is a frontend recreation of the Iventions website, developed as part of the Creative Frontend Roadmap.

The main focus is on recreating the website's modern visual design, interactive sections, smooth scrolling, creative animations, image/video presentations, and responsive behavior.

##  Main Sections

- Navigation
- Hero Section
- Events
- Exhibits
- Sports
- Creative Experiences
- Featured Projects
- Services
- Stories / Content
- Contact
- Footer

##  Design & Experience

The website focuses on creating an immersive digital experience through:

- Full-screen sections
- Large typography
- Creative layouts
- Image-based storytelling
- Video content
- Smooth transitions
- Scroll-based animations
- Interactive hover effects
- Section-to-section transitions
- Modern editorial-style design

The project uses images and video content to recreate the visual experience of the original Iventions website.
